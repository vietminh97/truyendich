Hướng dẫn lấy Gemini API Keys
  • 1
    Đăng nhập Google AI Studio.
  • 2
    Nhấp vào "Create API Key".
  • 3
    Ở mục "Choose an imported project" nhấp vào "Create project".
  • 4
    Đặt tên cho mỗi project để dễ phân biệt.
  • 5
    Nhấp vào "Create key".
  • 6
    Mỗi project chỉ tạo 1 API key.
  • Lưu ý: Toàn bộ API Keys của bạn luôn nằm trên máy của bạn, chúng tôi không thu thập data của bạn.
